# Interview Practice App

A browser-based interview preparation tool with question bank, timed mock interviews, microphone recording, an experience bank and locally stored revision progress.

## Run locally
Open `index.html` in a recent browser (Chrome or Edge). Microphone recording may require permission.

## Deploy on GitHub Pages
Open repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.

## Privacy
This app stores typed practice notes in your browser's local storage. Audio recordings are not uploaded and disappear when the page reloads. Do not enter confidential information into a publicly shared code repository.

This is an independent study tool and is not affiliated with, or endorsed by, Procter & Gamble. It is intended only for preparation before an interview; actual P&G interviews must be completed without real-time AI assistance.
